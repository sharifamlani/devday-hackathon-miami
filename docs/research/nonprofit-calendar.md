# Nonprofit calendar: event and campaign types

Research brief for the calendar's event types, Sat Nov 7, 2026. **[V]** = a retrieved source says it; **[U]** = a
planning default (vendor-only, sector knowledge or conflicting sources). Show [U] lead times in the UI as
"suggested default, staff-editable". Most sources are vendor blogs (Bloomerang, NEON, Classy, Bonterra), not
primary studies.

**Audience key:** G = Givers, N = Neighbors, C = Community. **Hard rule: purpose "ask" is never allowed for C.**

## Cadence

- **Thank within 48 hours** (Bloomerang); a board-member thank-you call within 48 hours is linked to about 39% more giving [S12].
- **2 to 3 touches in a new donor's first 90 days** improves retention [S12].
- **Year-end:** at least 3 emails (Bloomerang; average about 8 in December) [S2]; NEON's lighter pattern starts Dec 27 [S3].
- **About 30% of annual giving in December, about 10% in the last 3 days** (widely repeated; no primary dataset found) [S1, U].

## Guardrails

- **No donation asks to Community** (product rule).
- **Don't blast:** segment and coordinate channels [S2, S20].
- **Texting (TCPA):** every text says "Reply STOP to opt out"; honor STOP/QUIT/END/REVOKE/CANCEL/UNSUBSCRIBE immediately; one confirmation text is allowed [S21, S22]. Treat **express opt-in** as the default (sources conflict on what nonprofits need). Get counsel before a real launch.
- **Staff approve every send** (product rule).
